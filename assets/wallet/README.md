# Add to Apple Wallet / Google Wallet badges

Apple's official badge artwork, used by `app/card.html`:

- `apple-wallet-it.svg`
- `apple-wallet-en.svg`
- `apple-wallet-pl.svg`

Download the SVGs (signed in to the Apple Developer account) from
https://developer.apple.com/wallet/add-to-apple-wallet-guidelines/ and rename them as above.
Use them unchanged: Apple's rules forbid editing, dimming or recreating the badge.
Until a file is here, the card page shows its plain black button instead.

The EPS versions (RGB and CMYK) for posters and other print are in `print/apple-wallet-badge/`.

Google's official artwork (from Google Wallet's brand guidelines), unchanged:

- `google-wallet-it.svg`, `google-wallet-en.svg`, `google-wallet-pl.svg`: the badge the card page shows
- `google-wallet-button-*.svg`: the wider button version, kept in case it is needed
