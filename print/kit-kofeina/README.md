# Kit for Kofeina

Example cards for Kofeina (instagram.com/kofeina_coffee), a friend's café in Poland.
Their real logo isn't in here yet: the name is set in type, and the mark is ours, a drawing of
the caffeine molecule (kofeina = caffeine). Swap in their logo once they send it.

| File | What it is |
|---|---|
| `card-kofeina-simple-iphone.png` / `-android.png` | Simple: the molecule faint in the middle, brown dots, 10 stamps, free coffee |
| `card-kofeina-dark-iphone.png` / `-android.png` | Espresso: dark card, hexagon background, the molecule as the stamp, 8 stamps |

Rebuild: `node print/make-example-cards.js` (designs in `print/example-cards.html`).
